# Reel Viral Playbook

Ziel: Jedes Kurzvideo ist vor dem Dreh so gebaut, dass es die ersten 3 Sekunden übersteht, bis zum Ende geschaut und geteilt oder gespeichert wird.

## 1. Vor dem Skript: Idee prüfen

Beantworte in je einem Satz:
- **Für wen?** Eine konkrete Person, nicht «alle».
- **Welches Gefühl?** Überraschung, Neugier, Wiedererkennung, Ärger, Lachen, Ehrfurcht.
- **Warum teilen?** «Das muss X sehen», «das speichere ich», «endlich sagt es jemand».

Wenn eine Antwort fehlt: Idee schärfen, bevor du schreibst.

## 2. Hook (0 bis 3 Sekunden)

Immer 5 Hook-Varianten liefern, aus verschiedenen Formeln:

| Formel | Muster |
|---|---|
| Widerspruch | «Alle sagen X. Das ist falsch.» |
| Ergebnis zuerst | Endergebnis zeigen, dann den Weg |
| Konkrete Zahl | «3 Fehler, die dich 1000 Follower kosten» |
| Direkte Ansprache | «Wenn du [Situation], hör auf mit …» |
| Neugierlücke | «Das hat mir niemand über … gesagt» |
| Vorher/Nachher | Visueller Kontrast in Frame 1 |
| Geheimnis/Insider | «Was Profis nicht erzählen …» |
| Fehler eingestehen | «Ich habe 2 Jahre lang … falsch gemacht» |
| Challenge | «Ich habe 7 Tage lang … probiert» |
| Provokante Frage | Frage, auf die jeder sofort eine Meinung hat |

Regeln: Hook gesprochen **und** als Text im Bild. Bewegung oder Schnitt in der ersten Sekunde. Kein «Hallo, ich bin …».

## 3. Skriptstruktur

1. **Hook** (0–3 s)
2. **Kontext / Einsatz** (3–8 s): Warum das wichtig ist, was man verliert, wenn man weiterwischt
3. **Inhalt** (Kern): Ein Gedanke pro Satz, Pattern Interrupt alle 3–5 Sekunden (Schnitt, Zoom, B-Roll, Text)
4. **Payoff**: Das Versprechen aus dem Hook einlösen
5. **Loop oder CTA**: Letzter Satz führt zurück zum Anfang, oder genau ein CTA (speichern, folgen, Kommentar-Keyword)

Länge: so kurz wie möglich. Richtwerte 7–15 s für Unterhaltung, 30–60 s für Mehrwert.

Ausgabe als Tabelle: Zeit | Gesprochen | On-Screen-Text | Bild/B-Roll.

## 4. Packaging

- **Cover**: 3–5 Wörter, gross, lesbar im Grid (1080×1920, wichtiges in die mittleren 1080×1350)
- **On-Screen-Text**: Untertitel plus Schlagwort-Overlays, nie die untere Fläche verdecken (UI)
- **Caption**: erste Zeile ist ein zweiter Hook, danach Mehrwert, ein CTA
- **Audio**: Trend-Sound leise unterlegen oder Originalton; Sprache klar

## 5. Social SEO

- Hauptsuchbegriff gesprochen in den ersten 5 Sekunden
- Derselbe Begriff im On-Screen-Text und in der ersten Caption-Zeile
- 3–5 präzise Hashtags statt 30 generischer
- Alt-Text bzw. Videotitel mit Suchbegriff

## 6. Viral-Checkliste (Score 0–100)

| Kriterium | Punkte |
|---|---|
| Hook stoppt das Scrollen in < 2 s | 20 |
| Klares Zielpublikum und Gefühl | 10 |
| Ein einziger Kerngedanke | 10 |
| Pattern Interrupts mindestens alle 5 s | 10 |
| Payoff löst den Hook ein | 15 |
| Teil- oder Speichergrund vorhanden | 15 |
| Packaging (Cover, Text, Caption) stimmig | 10 |
| Social SEO umgesetzt | 5 |
| Loop oder ein klarer CTA | 5 |

Unter 70: konkret sagen, welche zwei Änderungen den grössten Sprung bringen. Ab 85: drehfertig.

## Stil

Natürlich gesprochen, kurze Sätze, keine KI-Floskeln, keine Gedankenstriche. Bei Instagram-Detailarbeit passende `ig-*` Skills ergänzen.
